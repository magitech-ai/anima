# Animas 2.0.0

Major release: Animas is now a fully declarative library kernel. No expression
evaluator is embedded or required.

## Breaking changes

- Removed the restricted JavaScript expression evaluator: `JsExprError`,
  `evaluate` and `interpolate` are no longer exported or available.
- Removed the `!!js` YAML tag and `__jsExpr` config dialect. Profiles using
  expressions no longer load; PyYAML reports the unknown tag at parse time.
- Removed config interpolation from the `internal/config` waterfall and from
  `inject`/`intercept` options. Config values are literal data.
- `disabled: !!js ...` is replaced by `disabled_on` / `enabled_on` entry
  options (platform lists validated at load time).

See ADR 0022, which supersedes ADR 0006 and records the evidence behind the
removal, including the deliberate exception to the normal deprecation policy
for this pre-adoption major release.

## Additive in this release

- Neutral `platform_name()` / `KNOWN_PLATFORMS` in `core.py`.
- `disabled_on` / `enabled_on` entry options with defined precedence and
  fail-loud validation.
- `profile_yaml.py` (introduced in 1.x) remains the plain-PyYAML load/dump and
  config-path location source.
