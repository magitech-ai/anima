# anima 0.3.0

This is a minor version bump. The versioning scheme stays in the `0.x` range
until the 1.0 milestone is declared; there is no major bump in this release.

## What shipped

Anima continues as the asynchronous micro-kernel and event pipeline engine
under the harness. The event waterfall, hierarchical context, dependency
injection, and component lifecycle contracts are unchanged in this release.

## Version and compatibility

- `__version__`, package metadata, the CLI `--version` fallback, and the parity
  note now report `0.3.0`.
- Before 1.0, breaking changes remain permitted. This release makes no runtime
  behavior changes; it only advances the version.

## Verification

Full suite at 100% statement and branch coverage; lint, format, and strict
type checks green; CI green on all legs.

Unresolved questions: none.
