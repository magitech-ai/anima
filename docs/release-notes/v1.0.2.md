# Animas 1.0.2

Documentation-only patch. No public API change.

Per the new uv-first tooling standard, the user-facing install command is now
`uv add animas` only. The previous `pip install animas` instruction is removed
rather than retained as a fallback. Version bumped so PyPI serves the corrected
README at the canonical project page.

The 1.0 compatibility contract is unchanged.

Verification: 1151 tests, 100% statement and branch coverage, `ruff check`,
`ruff format --check`, strict `mypy src`, and all CI legs green.
