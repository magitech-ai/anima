# Animas 1.0.0

Animas is now a stable, independent Python meta-framework of spatiotemporal
composability. The Cordis parity milestone is complete and recorded in
`PARITY.md`; future work follows the research paper's invariants and Animas's
own compatibility policy, not upstream releases.

## Highlights

- Public API is covered by `docs/COMPATIBILITY.md` (SemVer: additive in `1.x`,
  breaking only in `2.0.0` with deprecation where feasible).
- Completed the rc.13 kernel/paradigm port, including revertible effects,
  reactive coeffects, unified context, inertial lifecycle, configuration
  reconciliation, HMR, and the `fs` watch service.
- Hardened correctness: circular-dependency detection, serialized config
  updates, compensating commit rollback, rename pre-flight and registry rekey.
- Removed the DSH-fork extension set (volatile, legacy watcher, uv package
  service, `loader.builtins`/`exit`) and the unused Magitech-original
  CLI/server/HTTP surfaces. Animas is a library kernel; hosts own those edges.

See ADRs 0013–0018 for the decisions and `PARITY.md` for the conformance
evidence.

## Verification

`1148` tests passed with 100% statement and branch coverage; `ruff check`,
`ruff format --check`, `mypy src`, and all CI legs green at release.
